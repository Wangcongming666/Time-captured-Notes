# 实施与设计基线的差异

2026-11-01。原架构MD、PDF、图和schema保留为审批基线；本文说明已落地工程，不能将设计期“未实现”措辞当作当前状态。

| 项目 | 实施结果及理由 |
|---|---|
| 技术风格 | Java21、Vue3、MySQL、MyBatis-Plus、Redis、RabbitMQ，八模块单体，Cookie会话和CSRF；未改为微服务或React |
| 领域表达 | 类图保留概念领域模型；Java本版以NoteRules/PracticeRules/IdentityRules、应用服务及仓储Map快照表达聚合，未声称每个概念类都生成同名Java实体；UserRecord为实际MyBatis-Plus PO |
| 仓储 | 身份用户PO实际使用MyBatis-Plus；复杂锁及批量查询使用同一DataSource的prepared JDBC仓储，保留领域接口，不把BaseMapper暴露给web |
| 编译依赖 | domain无Spring/platform依赖；跨模块业务在workflows通过api编排；技术维护事务可在platform.application；ArchUnit与脚本均检查 |
| 跨域媒体 | 实际媒体绑定由content统一写t_note_media/t_practice_media，collection维护实践聚合；仅作为资源关联技术适配，不允许content更改实践业务状态；workflow控制事务 |
| 事务与消息 | 定向Outbox、数据库短租约、持久化mandatory发布及confirm、事务Inbox、手动ACK；网络发布不占数据库事务。1秒最多50条，消费者每队列1–2并发，是个人环境的收敛配置 |
| 生命周期 | revision与version分开；公开笔记修改立即转PENDING；公开反馈绑定源revision，源变化后不自动恢复；审核统一按源笔记→实践→审核行的顺序加锁 |
| 媒体 | 实际解码/像素与大小限制、重编码去EXIF、随机存储名、实时授权；WebP使用ImageIO插件。每10分钟分批清理24小时以上无任何业务引用的STAGED/DELETED媒体，失败重试 |
| 限流与代理 | Redis Lua计数，登录账号5/IP20、用户写30/上传10、IP读120每分钟；Redis故障采用半额本机配额，最多1万个本地键。Nginx覆盖XFF，Tomcat仅信任内部代理；后端无公网端口 |
| 推荐与降级 | 120秒候选快照和签名游标，40/30/20/10可解释排序；Redis不可用时当前首屏可读，无法继续快照分页；快照丢失返回409并提示刷新。这是实施限制，未冒充完整稳定分页降级 |
| 搜索 | prepared SQL对标题/正文/作者做转义LIKE，支持最新/热度；保留ngram FULLTEXT索引供后续优化，本版未以FULLTEXT排名宣称搜索相关性 |
| 接口 | 增加GET admin/users与admin/topics；77个真实操作，实施契约放03-源码/docs/api/openapi.yaml。公开、本人、管理DTO分开；新增布尔互动字段、作者名、排名位置、热门话题字段 |
| 分页 | 后端签名游标；管理、收藏/实践、个人主页独立游标并去重。动态排行按当前指标及id排序，翻页时指标变化应刷新，不宣称跨页快照固定 |
| 统计口径 | 浏览30分钟窗口去重；点赞/收藏/评论为当前有效计数；日趋势为动作次数。收藏加入/移出按夹计次，删除整夹不折算手工移除动作；热门话题按期间公开发文的当前点赞汇总 |
| 比率与日期 | 治理结案率、实践完成率均按本期创建批次为分母；空分母显示暂无数据。DAU跨日累加显示活跃人日，日平均时长不直接跨日相加；calculatedAt为查询时间，未伪称事件消费水位 |
| 物理部署 | 当前只有本地Compose，唯一宿主入口127.0.0.1:8080；三个基础服务只在内部网络，不额外开放宿主数据库端口。app就绪后web启动，无公网/域名/云服务器 |
| CI与证据 | 本地真实测试与远程Actions分别记录；未验证的性能、长期故障恢复、六周历史、本人使用反思不填写虚假通过 |

后续若更改模块边界、媒体统一适配或数据库拆分，应新增ADR并重新核对依赖、事务和HTTP契约，而不是修改既有迁移历史。
