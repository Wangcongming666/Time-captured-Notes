# 项目专用开发 Skill

三个包均包含七项规范和可执行Python脚本。Python3为运行前提，arch-doc-sync还需PyYAML。

- [project-scaffold](project-scaffold/SKILL.md)：八模块目录及安全环境模板。
- [module-generator](module-generator/SKILL.md)：参考骨架与分层扫描。
- [arch-doc-sync](arch-doc-sync/SKILL.md)：HTTP路由与OpenAPI同步。

脚本不是完整业务生成器，不代替审核和集成测试。实际使用记录见usage-log.md。
