# 拾光笔记 · Time-captured Notes

个人软件体系架构课程项目，复刻小红书的核心图文社区，并加入可解释推荐与收藏实践闭环。

技术：Java 21、Spring Boot、MyBatis-Plus、MySQL、Vue 3、Redis、RabbitMQ。

- `01-架构设计文档/`：五视图、ADR、数据与接口契约、开发计划。
- `02-开发Skill/`：项目专用AI开发规则与可执行资产。
- `03-源码/`：前后端、SQL、Compose、测试与运行指南。
- `docs/执行记录.md`：真实开发进展、验证结果与设计变更。

仓库按可验证业务切片提交。课程要求≥25次有意义提交、覆盖≥6周；历史日期不伪造。当前开发状态以执行记录与实际测试为准，不将文档中的性能目标当作测试结果。
